# 구현 로드맵 — 포트폴리오 v2.1 "Film & Stage"

> 브랜치 전략: `main` = v1 유지 → `v2` 브랜치에서 개발 → 완성 후 병합·배포.
> v2(R3F 3D 시네마) 페이즈 1–5 산출물 중 3D 씬은 폐기, 오버레이 콘텐츠·케이스 페이지는 재사용.

## MVP 라인

**CH1 필름(문+스크럽 영상) + CH2 랜딩 표지(패럴랙스+pin) + CH3 갤러리 + `/work/*` 3장**
— 이 4가지가 되면 공개 가능. CH4–6은 HTML 리빌 위주라 이후 붙여도 흐름이 성립한다.

## 페이즈

| # | 페이즈 | 산출물 | 완료 기준 |
|---|--------|--------|-----------|
| 1 | 리셋 | 문서 재작성, 영상 인코딩, 의존성 교체(3D 제거·GSAP/motion), 3D 씬 삭제 | `bun run build` 통과 |
| 2 | CH1+CH2 | 문 개폐 스크럽, 영상 스크럽(+일반 재생 폴백), 랜딩 5레이어 패럴랙스 + pin | 역스크롤 시 필름 되감김·문 닫힘 |
| 3 | CH3+CH4–6 | 가로 스크롤 갤러리, GSAP 리빌, 지면 반전, 클로즈 | 전 구간 스크롤 1회 통과 자연스러움 |
| 4 | 폴리시 | reduced-motion·영상 실패 폴백, 모바일, OG·메타, 성능 | 중급 안드로이드 검수 |

## 페이즈 밖 (하지 않기로 한 것)

- 3D 캐릭터·WebGL 일체 (v2.1에서 폐기 확정)
- 사운드, 커스텀 커서, 다국어
