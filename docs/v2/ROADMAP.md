# 구현 로드맵 — 포트폴리오 v2

> 브랜치 전략: `main` = v1 유지 → `v2` 브랜치에서 개발 → 완성 후 main 병합·배포.
> 각 페이즈 완료 시 `v2` 브랜치에 커밋 단위로 기록.

## MVP 라인

**CH1 (포털+달려오는 캐릭터) + CH2 (화이트 리빌·포즈·네임) + CH3 (갤러리 3전시물) + `/work/*` 3장**
— 이 4가지가 되면 공개 가능. CH2는 본문의 표지라 MVP에 포함. CH4·CH5·CH6은 HTML 위주라 이후 붙여도 흐름이 성립한다.
