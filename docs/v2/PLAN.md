## 1. 한 줄 컨셉

**"검은 문이 열리고, 달려온 보미가 하얀 무대 위에서 포즈를 잡는다."**

- 검은 포털(히어로)에서 캐릭터가 달려와 문을 열고 나오면, 세계가 **화이트로 반전**되고 캐릭터가 멋있는 포즈로 정지 — 옆에 영문 네임 타이포. 여기서부터 포트폴리오 본문이 시작된다.
- 주인공은 1명 — hip-vinyl-v2 스타일의 3D 캐릭터. 전 구간에 등장하며 스크롤에 따라 달리고, 포즈 잡고, 걷고, 마지막에 정면으로 인사한다.
- 스크롤이 곧 카메라이자 타임라인. oryzo.ai / lenis.dev처럼 스크롤 위치가 모든 시네마를 구동하고, 역스크롤 시 되감긴다.
- 흑백 반전이 리듬을 만든다: **검정(포털) → 흰색(리빌·본문) → 검정(클로즈)**.

## 2. 디자인 시스템 (순수 흑백 · 반전 구조)

superdesign 드래프트의 토큰에서 앰버·틸을 제거하고 무채색으로 치환. 지면(ground)이 챕터에 따라 검정↔흰색으로 반전된다.

### 2.1 컬러 토큰

```css
:root {
  /* 다크 지면 (CH1 포털 · CH6 클로즈) */
  --dark-ground: #0a0a0b;
  --dark-ink: #f2f0eb;

  /* 라이트 지면 (CH2 리빌 ~ CH5 기록) */
  --light-ground: #f4f2ed;   /* 순백보다 약간 본톤 — 브루탈리즘 종이 느낌 */
  --light-ink: #0a0a0b;

  --ink-2: #8a8a87;          /* 보조 텍스트 (양쪽 지면 공용) */
  --muted: #6e6e6c;          /* 캡션·eyebrow·메타데이터 */
  --hairline-on-dark: rgba(242, 240, 235, 0.14);
  --hairline-on-light: rgba(10, 10, 11, 0.16);
}
```

- 액센트는 **색이 아니라 처리**로 만든다: 아웃라인 타이포(`-webkit-text-stroke`), 반전 블록, 1px 헤어라인, 4px 도트만 허용.
- 고정 요소(nav·진행도 인디케이터)는 `mix-blend-mode: difference`로 지면 반전에 자동 대응.
- 금지: 그라데이션 배너, 벤토 그리드, 글로우(히어로 중앙 도트 제외), 드롭섀도(케이스 페이지 덱 카드 제외), 네온, 퍼플, 글래스모피즘.

### 2.2 타이포

| 역할 | 폰트 | 처리 |
|------|------|------|
| 워드마크·디스플레이·영문 네임 | Syne 600–800 | tracking −0.02em ~ −0.03em |
| 한글 스테이트먼트·본문 | SUIT Variable (지오메트릭, Syne 굵기에 맞춤) | tracking 타이트 |
| 소형 UI·라벨 | Sora 400–600, 10.5–16px | 라벨은 uppercase, tracking .12–.15em |

Pretendard·세리프·장식 서체 금지 (드래프트 제약 유지).

### 2.3 3D 무대·캐릭터 룩

- 다크 무대(CH1·CH6): 검은 공간 + 포그 + 화이트 키라이트 1 + 림라이트 1.
- **라이트 무대(CH2~CH5): 균일한 화이트 시클로라마(무한 배경) + 소프트 섀도** — 제품 촬영 스튜디오 느낌. 캐릭터 접지 그림자가 유일한 어두움.
- 캐릭터: `sian-bomi-3d/04-explore/hip-vinyl-v2.png` 시안 기준 — 바이닐 피규어 질감(약한 스페큘러), 체크 셔츠·데님·크림 부츠.
- 흑백 통합: 캐릭터 텍스처는 유지하되 저채도 그레이딩(saturation 0.1–0.25, 파라미터로 조정). 화이트 무대에서는 캐릭터가 화면의 유일한 저채도 컬러 덩어리 = 시선 고정.
- 포스트프로세스: 필름 그레인 아주 약하게, 비네트는 다크 무대에서만. 블룸 금지.

## 4. 스크롤 챕터 플로우 (진행도 0→1)

- 전체 스크롤 높이 약 **800vh** (구현하며 조정). 캔버스는 `position: fixed`, HTML 타이포 레이어가 위에 얹힘.
- **바인딩 규칙**: 카메라·캐릭터·포털·지면 반전은 스크롤 위치에 바인딩(역방향 재생 가능). 텍스트 리빌은 1회성(다시 사라지지 않음).
- 챕터 경계에서 카메라 방향·지면 색이 바뀐다 — "스크롤에 따라 방향이 달라지는" 감각의 핵심.

### CH1. PORTAL — 검은 문이 열린다 `[0.00 – 0.14]`

첫 화면(정지 상태)은 닫혀 있다:

```
[검은 패널 2장이 중앙에서 맞닿음. 중앙에 화이트 도트 2개(4px)]
              BO MI.
TL: KIM BOMI · FRONTEND   TR: 2026
BL: KROFFLE               BR: SEOUL
              ↓ Scroll
```

| 요소 | 애니메이션 (스크롤 바인딩) |
|------|---------------------------|
| 패널 2장 (HTML) | 각자 자기 폭 이상 바깥으로 translateX — 첫 700px 스크롤에서 100px 이상 크게 이동 |
| 워드마크 `BO` + `MI.` | scale 1 → 1.18, letter-spacing 0 → −0.04em, `BO`는 왼쪽 끝·`MI.`는 오른쪽 끝으로 자기 폭의 ~50% 이동 |
| 중앙 도트 2개 | 대각 반대편 코너로 이동 |
| 3D 무대 | 문 틈으로 보이는 검은 공간, scale 1.12 → 1.0 정착 |
| **캐릭터** | 저 멀리(z −40)에서 **Run 루프**로 카메라를 향해 달려옴 (z −40 → −6) |
| 카메라 | 정면 고정 + 마우스 패럴랙스 (±0.3 유닛, 감도 낮게, lerp) |

- 인터랙션 비트 ①: 마우스 패럴랙스.
- reduced-motion / no-JS: 문이 이미 열린 완성 상태로 시작.

### CH2. REVEAL — 하얀 무대, 포즈 `[0.14 – 0.26]` ★ 개정

문을 통과하는 순간 세계가 반전된다. 여기가 포트폴리오 본문의 표지.

| 진행도 | 요소 | 애니메이션 |
|--------|------|-----------|
| 0.14–0.18 | **지면 반전** | 캔버스 클리어컬러·포그·HTML 배경이 검정 → `--light-ground`로 lerp (스크롤 바인딩, 역스크롤 시 다시 어두워짐) |
| 0.14–0.19 | 캐릭터 | 달리던 속도가 잦아들며 **Run → Pose 크로스페이드** — 힙한 스탠스로 정지 (미세한 breathing만 남김) |
| 0.16–0.26 | 카메라 | 캐릭터를 **화면 왼쪽 1/3 지점**에 프레이밍하며 정착 (살짝 로우앵글 — 피규어가 당당해 보이는 각) |
| 0.18– | 타이포 (1회 리빌) | **화면 오른쪽**에 영문 네임 스택이 순차 리빌 |

오른쪽 타이포 스택 (Syne, `--light-ink`):

```
FRONTEND                    ← Sora uppercase 라벨, tracking .15em
KIM                         ← Syne 800, clamp(64px, 10vw, 160px)
BOMI.                       ← 같은 크기, 마침표는 아웃라인 스트로크
DEVELOPER · SEOUL · 2026    ← Sora 10.5px uppercase, muted
```

- 레이아웃: **왼쪽 = 3D 캐릭터, 오른쪽 = 텍스트** (모바일: 캐릭터 상단, 텍스트 하단 세로 스택).
- 네임 타이포는 리빌 후에도 스크롤에 아주 약한 패럴랙스(위로 8–12px)로 살아있게.
- 이 장면 하단에 얇은 헤어라인 + `↓ WORK` 힌트 — "이제 밑에서 포트폴리오 내용 시작"의 신호.

- 홈 복귀 시 CH3 위치로 스크롤 복원 (사용자가 흐름을 잃지 않게).
- 덱 카드에만 드롭섀도 허용 (`0 18px 40px rgba(0,0,0,.45)`).

## 8. 성공 기준

- 첫 5초: "문이 열리고 누군가 달려온다" — 개발자 포트폴리오라는 인상보다 장면이 먼저 남는다.
- 리빌 장면이 표지로 기능한다: 포즈 + `KIM BOMI` 타이포가 스크린샷 한 장으로 공유 가능한 그림일 것.
- 면접관이 기억할 것 1개: 숫자 하나(권한 훅 ~90개 파일 또는 블로그 100+)와 캐릭터.
- 스크롤을 올리면 문이 다시 닫히고 무대가 다시 어두워진다 (역재생이 완전할 것).
- M1 Mac / 중급 안드로이드에서 60fps 근접, 실패 시 우아한 폴백.
- `/work/*`는 자소서 밀도의 읽기 페이지 — "예쁜데 뭐 했는지 모름"을 만들지 않는다.
