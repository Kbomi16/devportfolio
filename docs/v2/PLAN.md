읽기가 우선. 3D는 없고, 드래프트의 "던지는 슬리브 덱"을 2D 헤더 액센트로 재활용.

```
[헤더: 슬리브 카드 1장 (드래그로 던지면 다음 프로젝트 카드) + 프로젝트명]
제목 · 한 줄 역할 · 기간 · 스택
문제
내가 한 선택
결과 (숫자 1개만)
배운 점
[라이브 링크 / GitHub / 스크린샷]
← 이전 · 다음 프로젝트 →   /   ← 홈으로 (스크롤 위치 복원)
```

- 콘텐츠는 `letter/portfolio.md`의 사실만 사용. 문제→선택→결과 구조 유지.
- 홈 복귀 시 CH3 위치로 스크롤 복원 (사용자가 흐름을 잃지 않게).
- 덱 카드에만 드롭섀도 허용 (`0 18px 40px rgba(0,0,0,.45)`).

## 8. 성공 기준

- 첫 5초: "문이 열리고 누군가 달려온다" — 개발자 포트폴리오라는 인상보다 장면이 먼저 남는다.
- 면접관이 기억할 것 1개: 숫자 하나(권한 훅 ~90개 파일 또는 블로그 100+)와 캐릭터.
- 스크롤을 올리면 문이 다시 닫힌다 (역재생이 완전할 것 — lenis/oryzo 감각의 척도).
- M1 Mac / 중급 안드로이드에서 60fps 근접, 실패 시 우아한 폴백.
- `/work/*`는 자소서 밀도의 읽기 페이지 — "예쁜데 뭐 했는지 모름"을 만들지 않는다.
